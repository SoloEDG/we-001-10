# 灰烬渡口

安装：`npm ci`

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:18071。

## 本地音效

`public/audio/` 内的 WAV 由 `scripts/generate-audio.py` 离线合成（确定性、无版权依赖）：

```
python3 scripts/generate-audio.py   # 重新生成全部 18 个素材
```

运行时不访问网络。首次点击“♪ 启动音效”或回放“播放”后，浏览器才会创建
AudioContext 并解码素材；之后实战与回放共用同一条事件时间线：

- 移动：按路径实际经过的地形逐格落脚步（浅滩更慢、密林更重、高地更脆）；
- 技能：按施法者职业选择施法音，再依据结算结果叠加命中/治疗/状态音；
- 结束行动：交接音，若灼烧在此时结算则追加灼烧音，胜负揭晓时追加结束音。

回放调度由历史事件时间戳推导，不依赖界面按钮；拖动进度条只预览最终落点，
松开后试听该步，暂停/重新部署会停止所有已排程声音。音频面板可为每个音效
设置 ±900ms 偏移并逐条试听，偏移按“步骤类型 + 角色 + 音效”保存在本地。
素材损坏时只跳过对应音效并在面板列出缺失项。
